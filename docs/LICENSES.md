# フォントライセンス

この文書は、KumiTypeが扱うソースフォントと生成フォントのライセンス・著作権情報の扱いを整理したものです。ソフトウェア自体のライセンスとフォントのライセンスは区別して扱います。

[ドキュメント一覧](README.md) · [プロジェクトREADME](../README.md)

## ライセンス文書の扱い

- 取得したソースの `OFL.txt` または `LICENSE` を `source/` 以下へ保存します。
- 生成フォントの Copyright/License メタデータには、元となる両ソースの情報を保持します。`package` 時には元文書も同梱します。
- 個別ライセンス文書は、ソースロックに `<書体ID>-license`(例: `plex-license`)という可読なIDで登録します。
- ライセンス文書が不足する場合は `package` が失敗します。取得と登録の手順は[ソースフォント](FONT_SOURCES.md)を参照してください。

## Reserved Font Name の確認状況

取得済みの固定ソースについて、取得文書に明示された Reserved Font Name を確認した結果は次のとおりです。全ソースのRFN・再配布条件の個別レビューが完了したわけではありません。

| ソース | 明示されたReserved Font Name |
| --- | --- |
| Cascadia | Cascadia Code |
| IBM Plex | Plex |
| Noto (Adobe由来) | Source |
| BIZ / LINE Seed / M PLUS 1/2 / Zen Kaku | 取得文書の著作権宣言に明示なし |

## 生成ファミリー名

生成ファミリー名は `プロジェクト名 + 出力名 + ベース系列の表示名` の形式で、たとえばPlex由来の生成ファミリー名は「KumiType IBMJP …」となります。元のファミリー名は生成名に使用しません。

## ソフトウェアのライセンス

KumiTypeのPythonコードと文書は、ルートの `LICENSE` に記載するMIT Licenseです。このライセンスはダウンロードするフォントや生成フォントには適用しません。各フォントには元のOFL文書・著作権情報を維持します。

## リポジトリに含めないもの

GitHubリポジトリにはビルドシステムのコード・設定・文書・テストのみを含めます。元フォント、生成TTF/ZIP、キャッシュ、第三者ドキュメントの取得抜粋は追跡しません。フォントを別途配布する場合は、元ライセンス・著作権・RFN条件の確認が必要です。
