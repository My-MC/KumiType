# フォントライセンス

取得したソースのOFL.txtまたはLICENSEをsource/以下へ保存します。
生成フォントのCopyright/Licenseメタデータには両ソースの情報を保持し、
package時には元文書も同梱します。元のファミリー名は生成名に使用しません。

ライセンス文書が不足する場合はpackageが失敗します。ソフトウェア自体の
ライセンスとソースフォントのライセンスは区別してください。
全ソースのRFN・再配布条件の個別レビューはまだ完了していません。

取得済み固定ソースのライセンス先頭を確認した結果:

| ソース | 明示されたReserved Font Name |
| --- | --- |
| Cascadia | Cascadia Code |
| IBM Plex | Plex |
| Noto (Adobe由来) | Source |
| BIZ / LINE Seed / M PLUS 1/2 / Zen Kaku | 取得文書の著作権宣言に明示なし |

Plex由来の生成ファミリー名は「KumiType IBMJP ...」とします。
過去のbuild/Plexの試験生成物は旧命名であり、配布対象にしないでください。
実行中の旧コードビルドも旧名を使用するため、完了後に最新版での再生成が必要です。

KumiTypeのPythonコードと文書はルートLICENSEに記載するMIT Licenseです。
このライセンスはダウンロードするフォントや生成フォントには適用しません。
各フォントには元のOFL文書・著作権情報を維持します。

GitHubリポジトリにはビルドシステムのコード・設定・文書・テストのみを含めます。
元フォント、生成TTF/ZIP、キャッシュ、第三者ドキュメントの取得抜粋は追跡しません。
フォントを別途配布する場合は元ライセンス・著作権・RFN条件の確認が必要です。
